# Security policy

## Supported versions

MobSimLab is in pre-release development (Phase 0). Security fixes go to the `main` branch until the first release.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/homlo-bike/MobSimLab/security/advisories/new). Do not open a public issue.

We aim to acknowledge reports within 7 days and to publish a fix and advisory within 90 days. We credit reporters who wish to be named.

## Deployment model

MobSimLab is designed for self-hosting on a private network, not for direct exposure to the internet. See `docs/architecture/05-security-users.md` and `docs/security/threat-model.md`.
